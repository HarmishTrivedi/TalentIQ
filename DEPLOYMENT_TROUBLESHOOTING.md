# 🔧 Deployment Troubleshooting Guide

## ❌ Current Issue: Project Not Running on Render

### 🔍 Issue Identified

**Error**: `ValidationError: debug - Input should be a valid boolean, unable to interpret input [type=bool_parsing, input_value='release', input_type=str]`

**Root Cause**: The `DEBUG` environment variable on Render has an invalid value `'release'` instead of a boolean (`true` or `false`).

---

## ✅ SOLUTION: Fix Render Environment Variables

### Step 1: Login to Render Dashboard
1. Go to https://dashboard.render.com
2. Login with your account

### Step 2: Fix Backend Service Environment Variables
1. Click on **talentiq-backend** service
2. Go to **Environment** tab
3. Find the `DEBUG` variable
4. Change value from `release` to `false`
5. Click **Save Changes**

## 🚀 Deployment Steps

### 1. Push Latest Changes to GitHub
```bash
cd ai-recruitment-system
git add .
git commit -m "fix: update email service and environment configuration"
git push origin main
```

### 2. Verify render.yaml
The `render.yaml` file should have:
```yaml
services:
  - type: web
    name: talentiq-backend
    runtime: python
    rootDir: ai-recruitment-Backend
    buildCommand: pip install -r requirements.txt
    startCommand: uvicorn app.main:app --host 0.0.0.0 --port $PORT
    envVars:
      - key: DEBUG
        value: false  # MUST BE BOOLEAN
```

### 3. Check Render Dashboard
1. Go to https://dashboard.render.com
2. Check both services:
   - talentiq-backend
   - talentiq-frontend
   - talentiq-db (database)

### 4. Monitor Deployment
- Watch the logs in real-time
- Look for successful startup messages
- Check for any errors

## 🐛 Common Issues & Solutions

### Issue 1: DEBUG Variable Error
**Error**: `ValidationError: debug - Input should be a valid boolean`

**Solution**:
- Go to Render Dashboard → talentiq-backend → Environment
- Change `DEBUG` from `release` to `false`
- Save and redeploy

### Issue 2: Database Connection Failed
**Error**: `Connection refused` or `Database not found`

**Solution**:
- Check if database service is running
- Verify `DATABASE_URL` is set correctly
- Ensure database is in the same region

### Issue 3: GROQ API Key Invalid
**Error**: `Authentication failed` or `Invalid API key`

**Solution**:
- Verify GROQ API keys are correct
- Check if keys have expired
- Try using `GROQ_API_KEY_2` as fallback

### Issue 4: CORS Errors
**Error**: `CORS policy blocked`

**Solution**:
- Update `ALLOWED_ORIGINS` to include frontend URL
- Ensure frontend URL matches exactly
- No trailing slashes

### Issue 5: File Upload Fails
**Error**: `Permission denied` or `Directory not found`

**Solution**:
- Render uses ephemeral storage
- Files are lost on restart
- Consider using S3 or Cloudinary for production
